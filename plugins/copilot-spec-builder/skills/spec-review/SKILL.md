# Spec Review Skill

## Purpose

Use this skill to review drafted customization assets for compliance, quality, and readiness.

## Inputs

- Drafted files and scope.
- Applicable instructions and acceptance criteria.
- Review priorities or questions.

## Workflow

1. Confirm target files and review objectives.
2. Check frontmatter, structure, references, and conventions.
3. Report findings ordered by severity.
4. List open questions and recommended actions.
5. If no findings exist, state that clearly and list residual risks.

## Output

- A concise Markdown review report with actionable next steps.
