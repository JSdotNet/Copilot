# Spec Plan Skill

## Purpose

Use this skill to produce a clear, approved plan for creating or refining a GitHub customization asset.

## Inputs

- Requested asset type and scope.
- Target files or folders.
- Acceptance criteria and constraints.

## Workflow

1. Gather context from existing assets and instructions.
2. Clarify ambiguous scope with focused questions.
3. Build an ordered plan with file targets and validation steps.
4. Capture decisions and assumptions.
5. Prepare handoff context for `spec-builder.agent.md` after approval.

## Output

- A Markdown plan ready for approval and execution handoff.
