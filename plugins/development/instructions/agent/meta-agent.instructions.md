# Agent Instructions

## Purpose

Define the standard for creating, structuring, and using agent files in the project.

## General Rules

- Agent files must follow `{role}.agent.md` naming.
- Agent assets must be in English.
- Frontmatter should include clear description and optional tools.
- Plugin-oriented requests should explicitly reference linked skills and resources.

## Validation Checklist

- [ ] Naming format is correct.
- [ ] Role and behavior are clear.
- [ ] References are included when relevant.
- [ ] Plugin composition expectations are addressed.
